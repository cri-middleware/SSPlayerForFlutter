# カスタマイズと自動化

このセクションは「プリビルドの `.ssab` を再生するだけ」の先へ進む読者向けです。自分で SpriteStudio
プロジェクトを作る、変換をビルドパイプラインに組み込む、ネイティブランタイムの届き方を制御する、
編集→実機のライブループを組む —— そんな場合はここが出発点です。

| やりたいこと | 参照先 |
|---|---|
| 自分の `.sspj` をランタイム用 `.ssab` に —— GUI・ブラウザ・CLI・保存時オートインポートで | [**アセットの準備（`.sspj` → `.ssab`）**](conversion.md) |
| `libssruntime` がアプリに届く仕組みを理解・上書きする、または純 Dart から使う | [**ネイティブランタイム**](native-runtime.md) |
| アプリ実行中に編集を即反映させる | [**ライブリロード**](live-reload.md) |

!!! tip "アニメを組み込むだけなら"
    アプリでアニメを再生したいだけなら、[利用者](../guide/install.md) セクションだけで完結します
    —— ここの内容は不要です。

このセクションはすべてデスクトップのツールまたはビルド時の作業で、**出荷アプリを重くしません**。
プレイヤーのランタイム自体は converter を一切積みません。
