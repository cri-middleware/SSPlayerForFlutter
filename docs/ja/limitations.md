# 制約と適用範囲

現行の SpriteStudio Player for Flutter で出荷する際に留意する制約とプラットフォーム固有の注意点です。
*できること*は [主な機能](index.md#key-features) と各ワークフローガイドを参照してください。

!!! note
    これは生きたドキュメントです。確認でき次第、項目を追加します。プレイヤーの進化に伴い記述や範囲は
    変わることがあります。

## プラットフォーム

**macOS**・**iOS（シミュレータ）**・**Android（エミュレータ）**・**Web（開発者プレビュー）** で確認済み。
未確認: **実機 iOS**（署名付き `iphoneos` スライス）と 32bit **`armeabi-v7a`** ABI の実行時。

ネイティブランタイム（`libssruntime`）は **Native Assets** のビルドフックがターゲットごとに配布します
—— CocoaPods も手動リンクも不要。**Web** には `dart:ffi` が無いため、Brain は SDK の wasm-bindgen
ビルドを `dart:js_interop` 経由で駆動し、Flutter アセットとして同梱、描画は常に Canvas バックエンドです。

## 描画

- **2 つの描画バックエンド。** 利用可能な環境では `flutter_gpu`（Impeller）、それ以外では dart:ui の
  **Canvas**（`Canvas.drawVertices`）。既定の `auto` がプローブして安全にフォールバックします。Web は
  常に Canvas。
- **ブレンドモード。** SpriteStudio はすべてのブレンドを固定機能の GPU ブレンドステートとして実現して
  いるため、どこまで厳密に再現できるかはバックエンドによって変わります。

    | SpriteStudio のモード | `flutter_gpu` | Canvas |
    |---|---|---|
    | `Mix` / `Add` | 厳密 | 厳密 |
    | `Screen` / `Screen2` / `Exclusion` | 厳密 | 厳密 |
    | `Mul` / `Mulalpha` / `Mul2` | 不透明な背面に対して厳密 | 不透明な背面に対して厳密 |
    | `Sub` / `Invert` | 厳密 | 不透明な背面に対して厳密（3 回描画） |
    | `Div2` / `Overlay2` | `Mix` として描画 | `Mix` として描画 |

    `flutter_gpu` はリファレンスのブレンドステートをそのまま設定するため、全モードをそのまま再現し
    ます。Canvas バックエンドでは `Sub` / `Invert` に対応する単一の `ui.BlendMode` が存在しない
    （Flutter の固定 enum に逆減算も dst 置換も無い）ため、同じジオメトリに対する 3 パスの標準ブレンド
    で厳密に再構成しています。追加コストはパーツあたり 2 回の描画と、そのパーツがバッチにまとめられ
    なくなること——`Sub` / `Invert` を多数のパーツで同時に使う場合のみ影響します。

    `Div2` / `Overlay2` が `Mix` になるのは意図的です（リファレンス実装にも GPU ブレンドの対応が無い）。

- **ブレンドは不透明な背面を前提とします。** 描画先を参照するモード（`Mul` / `Sub` / `Screen` /
  `Exclusion` / `Invert`）は、下にあるピクセルが不透明な場合にエディタと一致します（SpriteStudio 自身も
  不透明なターゲットへ描画する前提）。透明な領域では結果が異なり、バックエンド間でも差が出ます。Canvas
  バックエンドはアプリがウィジェットの背後に描いた内容に対してブレンドしますが、`flutter_gpu` は自前の
  オフスクリーン内でブレンドするため、アニメーション自身のピクセルしか見えません。両者を一致させたい
  場合は、ブレンドを多用するアニメーションに不透明な背景レイヤーを持たせてください。

## 再生機能の制約

これらは共有の `libssruntime` 由来で、全プラットフォーム・全バックエンドに共通します。すべての公式
Player に共通する制約でもあるため、詳しい説明とその他の共通制約（embedded モード、`.ssab` の入力検証
など）はポータルの
**[共通の制限事項](https://cri-middleware.github.io/SpriteStudio-Docs/ja/sdk/limitations/)**
にまとまっています。

!!! warning
    - **`independent = true` パーツ（Instance / Effect）は逆再生・シークが正しく動きません。**
      正しいのは順再生（順方向のフレームスキップ含む）のみです。
    - **シークは飛ばしたフレームのイベントを発火しません。** 発火するのは着地フレームの
      `UserData` / `Signal` / `Audio` のみです。
    - **逆再生の音声はありません。** 実効方向が逆（逆再生・ピンポンの戻り・負の速度）のとき、
      音声イベントはスキップされます。
    - **アニメブレンドは同一 `.ssab` 内のみ。** さらに、ブレンドする各アニメは同じパーツに同じ
      セルを割り当てる必要があります。
