# 制約と適用範囲

現行の SpriteStudio Player for Flutter で出荷する際に留意する制約とプラットフォーム固有の注意点です。
*できること*は [主な機能](index.md#key-features) と各ワークフローガイドを参照してください。

!!! note
    これは生きたドキュメントです。確認でき次第、項目を追加します。プレイヤーの進化に伴い記述や範囲は
    変わることがあります。

## プラットフォーム

**macOS**・**iOS（シミュレータ）**・**Android（エミュレータ）**・**Web（開発者プレビュー）** で確認済み。
未確認: **実機 iOS**（署名付き `iphoneos` スライス）と 32bit **`armeabi-v7a`** ABI の実行時。

ネイティブランタイム（`libssruntime`）は **Native Assets** のビルドフックがターゲットごとに配布します
—— CocoaPods も手動リンクも不要。**Web** には `dart:ffi` が無いため、Brain は SDK の wasm-bindgen
ビルドを `dart:js_interop` 経由で駆動し、Flutter アセットとして同梱、描画は常に Canvas バックエンドです。

## 描画

- **2 つの描画バックエンド。** 利用可能な環境では `flutter_gpu`（Impeller）、それ以外では dart:ui の
  **Canvas**（`Canvas.drawVertices`）。既定の `auto` がプローブして安全にフォールバックします。Web は
  常に Canvas。
- **ブレンドモード。** Canvas バックエンドでは `Sub` / `Invert` は `difference` に近似、`Div2` /
  `Overlay2` は `srcOver` にフォールバックします（Flutter の固定 enum では逆減算 / dst 置換を表現でき
  ない）。`flutter_gpu` バックエンドはより多くのモードを厳密に再現し（逆減算・Screen・Multiply 等）、
  `Exclusion` / `Invert` / 透明 Multiply のみ `srcOver` にフォールバックします。

## 再生機能の制約

これらは共有の `libssruntime` 由来で、全プラットフォーム・全バックエンドに共通します。

!!! warning
    - **`independent = true` パーツ（Instance / Effect）は逆再生・シークが正しく動きません。**
      `independent = true` の子は親タイムラインから切り離された独自の実時間クロックで走ります。親の
      **逆再生**と**シーク**は壊れ、正しいのは**順再生**（順方向のフレームスキップ含む）のみです。
    - **シークは飛ばしたフレームのイベントを発火しません。** 再生位置を直接ジャンプしても、通過した
      フレームの `UserData` / `Signal` / `Audio` イベントは発火せず、着地フレームのイベントのみ発火
      します。全イベントが必要ならジャンプせず 1 フレームずつ進めてください。
    - **逆再生の音声はありません。** 音声はアニメが時間的に前進する間だけ発火します。実効方向が逆
      （逆再生・ピンポンの戻り・負の速度）のときは音声イベントはスキップされます。
    - **アニメブレンドは同一 `.ssab` 内のみ。** `.ssab` をまたぐブレンドは非対応で、ブレンドする各
      アニメは**同じパーツに同じセル**を割り当てる必要があります。セルが食い違うとサイズ / 原点が
      ずれてポーズが壊れます。
