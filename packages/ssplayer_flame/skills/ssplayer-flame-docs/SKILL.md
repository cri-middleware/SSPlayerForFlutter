# SpriteStudio Player for Flutter — documentation

`references/` is the documentation of SpriteStudio Player for Flutter, as Markdown, from the
release this package came from, so it describes the API that version provides. The online
documentation, <https://cri-middleware.github.io/SSPlayerForFlutter/>, is built from the latest
release and can be ahead of this copy.

Start at [references/index.md](references/index.md): its table of contents links every page. The
Flame page is [references/guide/flame.md](references/guide/flame.md).
